if_else
-------
1) Take a number and check if it is even or odd.
2) Take a number and check if it is positive or negative.
3) Ask the user to enter their age : 
	if age ≥ 18 print "Adult" 
	else print "Minor"
	
4) Input marks from user and 
	if marks >= 40 then print "pass" ,
	else "fail".
	
5) Input a temperature. 
	If it’s >30, print "Hot", 
	else "Cool".
	
6) Ask the user for their gender ('M' or 'F'): 
	If 'M', print "Hello Sir"
	Else, print "Hello Ma'am"
	
7) Enter a character. Print:    and
	"Uppercase Letter" if capital, 
	"Not Uppercase" otherwise.
	
8) Enter your bank balance: 
	If ≥ ₹5000, print "Sufficient Balance"
	Else print "Low Balance Warning"
	
9) Input a number and print:
	"Divisible by 3" if divisible,
	"Not Divisible by 3" otherwise
	
10) Input a number and: 
	If divisible by either 3 or 5 → "Valid" 
	Else → "Invalid"
	
11) Input marks of two subjects:    and
	If both ≥ 40 → "Passed both" 
	Else → "Failed in one or both"
	
12) Input a number and: 
	If number is between 100 and 999, print "Three-Digit Number" 
	Else print "Not a Three-Digit Number"
	
13) Take two numbers from user and prints maximum from both number.
14) Take two numbers and prints print minimum from both number.
15) Input a number from user 
	if number is greater than 100 , then input another number from user and print sum of two numbers 
	else print number less than 100
	
16) Ask user for income: 
	If > ₹10,00,000 → "Taxable Income" and add 15 % tax on the income and print complete amount on screen 
	Else → "No Tax"
	
17) Input day number (1–7): 
	If 6 or 7 → "Weekend" 
	Else → "Weekday"
	
18) Write a program to check the entered character is vowel or consonant
19) Write a program to check whether the entered character is Uppercase or Lowercase


else_if_task
-------------
Ladder if..else Task
--------------------
1) Input marks and print grades:
	≥90 → Grade A
	75–89 → Grade B
	50–74 → Grade C
	<50 → Grade D
2) Enter a number and check:
	Positive
	Negative
	Zero
3) Enter time (in 24-hour format) and print:
	Morning (5–11)
	Afternoon (12–16)
	Evening (17–20)
	Night (21–4)
4) Take three numbers and print the largest one using else-if ladder.
5) Take three numbers and print the smallest one using else-if ladder.
6) Enter a month number (1–12) and print the month name:
	1 → January
	2 → February
	…
	12 → December
7) Enter a character and identify:
	Vowel (a, e, i, o, u)
	Consonant
	Digit
	Special character
8) Input total salary and classify:
	≥ 1,00,000 → High income
	50,000–99,999 → Middle income
	20,000–49,999 → Low income
	< 20,000 → Very low income
9) Enter number of working days and days present; calculate attendance %:
	≥ 90% → Excellent
	75–89% → Good
	50–74% → Average
	< 50% → Poor
10) Input electricity units used and decide rate:
	0–100 units → ₹2/unit
	101–300 units → ₹3/unit
	301–500 units → ₹5/unit
	500 units → ₹8/unit
11) Input two numbers and operator (+, -, *, /):
	Use else-if to perform the selected operation.
12) Enter triangle angles a, b, c:
	If valid (a + b + c = 180), check:
		All equal → Equilateral
		Any two equal → Isosceles
		All different → Scalene
		Else → Not a triangle
13) Input weight(in kg) and height(in meters) → calculate BMI and classify:
	BMI = weight / (height * height)
		BMI < 18.5 → Underweight
		18.5–24.9 → Normal
		25–29.9 → Overweight
		30+ → Obese
14) Enter student's total fee paid (from total ₹20,000):
		≥ 20,000 → "Fully Paid"
		15,000–19,999 → "75% Paid"
		10,000–14,999 → "50% Paid"
		< 10,000 → "Pending Payment"
15) Input number of leaves taken in month and input number of days in months:
	0 → Perfect Attendance
	1–3 → Excellent
	4–7 → Average
	7 → Warning Issued
16) Electricity Bill Calculator
Ask units consumed:
	If units ≤ 100 → ₹2 /unit
	Else if ≤ 300
		₹2 /unit for first 100
		₹3 /unit for next till 300
	Else
		 ₹2 /unit for 100
		 ₹3 /unit for 200
		 ₹5 /unit for rest
