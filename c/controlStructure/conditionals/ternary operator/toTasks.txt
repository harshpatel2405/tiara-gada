1. Even or Odd
Take a number from the user and use the ternary operator to check whether it is Even or Odd.

Example:
Enter number: 8
Output: Even


2. Pass or Fail
Take marks from the user and use the ternary operator.

Marks >= 40 → Pass
Marks < 40 → Fail

Example:
Enter marks: 65
Output: Pass


3. Greater Number
Take two numbers from the user and use the ternary operator to find the greater number.

Example:
Enter a: 25
Enter b: 18
Output: 25 is greater


4. Positive or Negative
Take a number from the user and use the ternary operator to check whether it is Positive or Negative.

Example:
Enter number: -5
Output: Negative
