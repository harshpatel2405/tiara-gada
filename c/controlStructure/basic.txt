operator 
--------
1. Arithmetic operator 
    +   -   *    /    % (return remainder)

     /   ->   5 / 2 -> 2  (int  / int = int) (int / float = float)
     %   -> 5 % 2 = 1


2. Relational Operator 
    <    5 < 6 -> 1     7 < 6 -> 0     6 < 6 -> 0
    >    5 > 6  -> 0    6 > 6 -> 0     7 > 6 -> 1
    <=   6 <= 6 -> 1
    >=   6 >= 6 -> 1
    ==   6 == 6 -> 1
    !=   5 != 6 -> 1


3. Assignment operator 
     =  -> assignment operator

4. Logical Operator 
    checks multi condition at a time 

    Logical and  -> &&  -> returns true when both conditions are true  
    Logical or   -> ||  -> returns true when any one of the condition is true
    Logical not  -> !   -> true -> false       false -> true


5. Increment /  decrement operator 
    Increment -> ++ -> increase value by 1 -> count = 4 => count++ -> count = 5
    Decrement -> ++ -> Decrease value by 1 -> count = 4 => count-- => count = 3

    Post Increment -- it will update after the task is completed
    count = 4
    a = count++; // post Increment  -> a = 4 , count = 5
    print(a)      4
    print(count)  5
    
    post decrement -- it will update after the task is completed
    
    pre Increment -- it will get updated first and then do the task
    count = 4
    a = ++count; // pre Increment  -> a = 5 , count = 5
    print(a)      5
    print(count)  5


    pre decrement -- it will get updated first and then do the task

    sizeof -- size in bytes 
    & -> ampersand (address of)
