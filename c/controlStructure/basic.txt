operator 
--------
1. Arithmetic operator 
    +   -   *    /    % (return remainder)

     /   ->   5 / 2 -> 2  (int  / int = int) (int / float = float)
     %   -> 5 % 2 = 1


2. Relational Operator 
    <    5 < 6 -> 1     7 < 6 -> 0     6 < 6 -> 0
    >    5 > 6  -> 0    6 > 6 -> 0     7 > 6 -> 1
    <=   6 <= 6 -> 1
    >=   6 >= 6 -> 1
    ==   6 == 6 -> 1
    !=   5 != 6 -> 1


3. Assignment operator 
     =  -> assignment operator

4. Logical Operator 
    checks multi condition at a time 

    Logical and  -> &&  -> returns true when both conditions are true  
    Logical or   -> ||  -> returns true when any one of the condition is true
    Logical not  -> !   -> true -> false       false -> true


5. Increment /  decrement operator 
6. special operator 
7. bitwise operator
