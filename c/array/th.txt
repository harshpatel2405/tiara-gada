Datatypes 
---------
Primitive  -- int , float , char , long , short , double -- inbuilt (names)
Derived    -- array [] , function () , pointer *  -- inbuilt(shapes)
User-Defined  -- union , structure , enum   -- inbuilt (names)

<==============================================================================>
Array 
-----
Array -- derived data type (shape : [])
Array -- collection of elements of same data type
Array Index starts from 0
Array Elements are stored contigously
